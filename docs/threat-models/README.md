# Threat models

One threat model per feature, using STRIDE + LINDDUN ([ADR-0049](../adr/0049-threat-modelling-method.md)). Security-labelled PRs must add or update the relevant model.

| File | Covers |
|---|---|
| [`_template.md`](_template.md) | Template to copy for a new feature: `<feature>.md` |
| [`platform.md`](platform.md) | Platform-wide trust boundaries, top threats and mitigations |
