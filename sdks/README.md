# sdks/: Non-JavaScript SDKs

One directory per language: `go`, `python`, `java`, `dotnet`, `swift`, `kotlin`, `react-native`, `flutter`, `php`, `ruby`, `rust-client`. Read-only publishing mirrors are generated by CI where an ecosystem requires a separate repository.

- **License:** Apache-2.0 (each SDK carries its own `LICENSE`)

- **Placement rules:** [ADR-0111](../docs/adr/0111-repository-organization-and-file-placement.md)
